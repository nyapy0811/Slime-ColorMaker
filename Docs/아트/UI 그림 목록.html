UI 그림 목록

지금 게임에 있는 UI와 HUD 화면 다섯 개를 장면 파일(UIScene, MainMenu)의 실제 위치와 크기대로 다시 그렸습니다. 지금은 모두 그림 없이 단색 사각형과 글자로만 되어 있습니다. 각 화면의 번호가 아래 '만들 그림' 번호와 같습니다.

기준 화면 1920 × 1080 그림 1픽셀 = 화면 3픽셀 (판 640 × 360) 만들 그림 6개 글자는 그림에 넣지 않음 (폰트)

만들 그림

크기는 '지금 화면 크기 ÷ 3'입니다. 늘어나는 그림(9-슬라이스)은 가장 작은 크기로 그리면 되고, 정확한 칸 크기는 그림을 넣을 때 메인 세션이 3픽셀 격자에 맞춥니다.

화면별 배치

모두 1920 × 1080 비율입니다. 점선 상자는 게임 속 기물 자리(예시), 숫자 상자는 예시 값입니다.

출처: Assets/Scenes/UIScene.unity, Assets/Scenes/MainMenu.unity, Assets/Scripts/UI/** (2026-11-20 기준, 커밋 3507686 뒤). 그림 규칙은 Docs/v2 UI 픽셀아트 규칙.md.

그림이 필요 없는 것: 화면 어둡게 하는 덮개(검정 60%), 화면 페이드(검정), 지금 시간·최고 시간 글자(폰트).
