UI 그림 목록

지금 게임에 있는 UI와 HUD 화면 일곱 개를 장면 파일의 실제 위치와 크기대로 다시 그렸습니다. 창·버튼·값 상자에는 직접 그리신 그림을 그대로 씌웠습니다. 각 화면의 번호는 아래 '그림' 번호와 같습니다.

기준 화면 1920 × 1080 그림 1픽셀 = 화면 3픽셀 그림 파일 6개 적용 · 남은 그림 1개 폰트 Galmuri 반영 2026-11-24 설정 화면

그림

크기는 그림 픽셀입니다(화면 크기 ÷ 3). 칠하기 방식은 Gray(흑백), Color(지금 색 × 밝기), Tint(채도만큼 흰색 → 지금 색) 세 가지입니다.

글자 (Galmuri)

폰트 1픽셀 = 화면 3픽셀이 되게 Galmuri11은 36, Galmuri9는 30을 기본으로 씁니다. 아래 화면 재현의 글자는 웹 폰트라 실제 게임의 픽셀 글자와 모양이 다릅니다.

폰트크기쓰는 곳
Galmuri1136버튼, 확인 창 문장, 진행 시간, 클리어 시간, 맵 목록 이름
Galmuri930값 상자 숫자, 최고 시간·최고 기록, 맵 상태, 기록
Galmuri11 Bold72창 제목(일시정지, 클리어), '맵 선택', 미리보기의 맵 이름
Galmuri11 Bold108메인 메뉴 제목

화면별 배치

모두 1920 × 1080 비율입니다. 점선 상자는 게임 속 기물 자리, 숫자와 맵 이름은 예시입니다. 버튼은 기본 밝기(0.85)로, 고른 맵은 푸른 틴트로 보입니다.
